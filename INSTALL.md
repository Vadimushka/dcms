# Установка DCMS

## Что потребуется

- PHP **8.1 или новее** (проверено на 8.1–8.5) с расширениями `pdo_mysql`,
  `mbstring`, `gd`, `json`, `session`;
- MySQL 5.7+ или MariaDB 10.3+ с базой и пользователем, имеющим права на неё;
- nginx с PHP-FPM или Apache с `mod_php`/`mod_rewrite`.

## Порядок установки

1. Распаковать архив в каталог сайта. Точка входа — `index.php` в корне.
2. Дать веб-серверу право записи:

   ```
   chmod -R 775 sys/files sys/tmp sys/logs sys/ini sys/languages sys/themes
   ```

3. Открыть в браузере `/install/` и пройти мастер: выбор языка, проверка
   платформы, подключение к базе, создание таблиц, учётная запись владельца.
4. После установки закрыть каталог `/install/` от посетителей — мастер
   перестаёт работать сам, как только появляется `sys/ini/settings.ini`, но
   каталог лучше удалить.

## Настройка веб-сервера

Движок держит страницы в `pages/`, а ссылки ведут на `/login.php`, `/faq.php`
и подобные, поэтому серверу нужно правило: если файла в корне нет — искать
его в `pages/`. На Apache это делает `.htaccess` из поставки, для nginx
готовый набор правил лежит в репозитории: `deploy/nginx-production.conf`
(там же запреты доступа к `sys/ini`, `sys/inc` и прочим служебным каталогам —
на nginx они обязательны, иначе настройки с паролем базы отдаются наружу).

## Обновление

Замена файлов движка поверх существующей установки с сохранением `sys/ini`,
`sys/files`, `sys/logs` и `sys/tmp`. После обновления открыть в панели
управления «Обновление структуры таблиц» — оно приведёт базу к новой версии.
